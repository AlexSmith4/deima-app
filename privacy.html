Privacy Policy: Deima Uploader

Last updated: September 30, 2026

What this app is

Deima Uploader is a private tool used by a single person, the app's owner. It uploads videos to the owner's own YouTube channel and manages that channel's video details (titles, descriptions, thumbnails).

Data accessed

The app uses YouTube API Services, with Google OAuth permission granted by the owner, to access only the owner's own YouTube channel. It does not access, collect or store data from any other user.

How data is stored

The OAuth token is stored privately by the owner and is used only to make YouTube API requests for the owner's channel. No data is sold, shared or transferred to any third party.

Revoking access

Access can be revoked at any time at Google Account permissions.

Third-party terms

This app uses YouTube API Services. By using it, you agree to be bound by the YouTube Terms of Service. See also the Google Privacy Policy.
